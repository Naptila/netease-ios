# 网易游戏 iOS 登录助手 (netease-ios)

在 Android 设备上通过网易官服游戏自带的 **MPay / GMBridge** 组件，直接登录同一网易账号下的 **iOS 端角色**。

全程**免 Root、免抓包、免修改游戏安装包或签名、不内嵌任何第三方登录 SDK**，账号验证完全在目标游戏客户端原生的网易登录窗口中完成。

---

## 核心特性

- **通用 MPay 支持**：不局限于单一游戏，支持直接从本机已安装应用中选择目标网易官服游戏，自动识别游戏代号（如 `ma75` 等）。
- **保留官方包体与签名**：不对目标游戏 APK 做任何重打包或注入修改。

---

## 适用前提

1. 目标游戏需为**网易官服客户端**（B 站服、应用商店渠道服等非网易官服账号体系不适用）。
2. 目标游戏客户端需开放导出网页桥组件 `com.netease.unisdk.gmbridge5.activity.GMWebviewActivity`（部分老架构或未导出该组件的客户端不支持，拉起时会有明确提示）。
3. 第三步准备文件传输支持两种通道（按需手动选择）：
   - **标准缓存方式（默认）**：通过 `<游戏包名>.widget_file_provider` 写入缓存目录（适用于《光·遇》等开放了缓存接口的游戏，免任何目录授权）。
   - **共享目录方式（SAF · 阴阳师等适用）**：针对未包含 `widget_file_provider` 的游戏（如《阴阳师》），手动切换为此方式后通过系统目录选择器授权内部存储 `Android/media`（或对应游戏子目录）写入一次性准备文件。

## 使用步骤

1. **选择目标游戏**
   打开本助手，点击顶部目标栏，从本机已安装应用列表中选择要切换的网易官服游戏。

2. **第一步：识别游戏当前账号**
   先打开目标游戏并**正常登录**你要切到 iOS 角色的网易账号，随后切回本助手点击 **「识别当前账号」**（识别有效期为 10 分钟）。

3. **第二步：进入游戏「切换账号」界面**
   识别成功后，进入游戏点击用户中心/设置中的 **「切换账号」**，停留在网易登录弹窗界面，再切回本助手。

4. **第三步：选择写入方式并注入 iOS 登录准备**
   - 一般游戏保持默认的 **「标准缓存方式」** 即可。
   - 若游玩《阴阳师》等未开放缓存接口的游戏，可在第三步选择 **「共享目录方式（SAF · 阴阳师适用）」**，首次执行时按提示在系统文件夹选择器中授权内部存储的 `Android/media` 目录。
   - 点击 **「已停在登录窗口，准备 iOS 登录」**，助手发送请求后会自动跳回游戏（部分游戏 SDK 不会向网页桥回传独立确认回调，助手状态会显示「未收到 SDK 确认」，属正常现象，直接在游戏内完成登录核对角色即可）。

5. **关键一步：关闭旧弹窗刷新列表后重新登录**
   > **重要提示（防卡死转圈）**：
   > 返回游戏后，**切勿直接点击旧账号列表上原有的账号**！因为旧会话已被替换，直接点击会导致一直转圈卡死。
   > 请务必先点击切换账号列表**右上角的「×」**关闭弹窗，再重新点开登录窗口以刷新账号列表，随后使用刚才同一个网易账号（账号密码或手机号验证码均可）重新登录，即可进入 **iOS 角色**。

### 日常切号常见问题

- **切换其他账号后，原本弄好的 iOS 号进游戏又变成安卓号了怎么办？**
  不用重新打开本助手！直接在游戏里点开 **「切换账号」**，把那个变成安卓号的账号**再点选登录一次**，就会直接变回 iOS 角色了。

- **想把账号彻底变回安卓角色怎么操作？**
  在游戏内的「切换账号」列表中**删掉该账号记录**，重新输入账号正常登录，就会恢复成安卓角色。

## 工作原理简述

1. **本地回环瞬时通信**：每次操作仅在本地回环地址 `127.0.0.1` 绑定随机端口并生成一次性 24 字节随机路径 Nonce，配合严格 `Host` / `Origin` 校验与 CSP 策略，45 秒超时或完成后立即销毁。
2. **读取游戏上下文（Step 1）**：拉起目标游戏的 `GMWebviewActivity`，通过 JS 桥调用 `gameContextInfo` 获取当前登录的账号标识与 `game_id` 代号。
3. **预置 iOS 客户端类型（Step 3）**：通过第三步选定的 `widget_file_provider` 缓存接口或已授权的 SAF `Android/media/<游戏包名>` 共享目录，写入一段不含登录凭据（`token: ""`）、标记 `pc_ext_info.src_client_type = 2`（iOS）与 `need_mask = true` 的临时 MPay 会话种子（完成后、恢复前台及下次启动时自动清理），并传入真实文件路径调用 `loadMpaySession` 加载，使后续在原版登录窗验证同一网易账号时携带 iOS 客户端标识。

## 构建说明

### 环境要求

- **Android Studio**：最新版本（支持 AGP `9.5.1`）
- **JDK**：11+（Gradle Daemon Toolchain 配置见 `gradle/gradle-daemon-jvm.properties`）
- **Android SDK**：`minSdk = 28`（Android 9.0），`compileSdk / targetSdk = 37`

### 命令行构建

```bash
# 构建 Debug 安装包
./gradlew assembleDebug

# 构建 Release 安装包
./gradlew assembleRelease
```

```text
app/src/main/

│   │   └── HttpRequest.kt            # 定界单次本地 HTTP/1.1 解析器
│   └── ui/
│       ├── BridgeScreen.kt           # 主界面、已安装应用选择器与三步引导卡片
│       ├── AppIcons.kt               # 内置矢量图标集（零额外图标库依赖）

    ├── drawable/                     # 自适应图标（背景层 / 前景层 / 单色层）

    ├── values/                       # 字符串与基础样式
```
