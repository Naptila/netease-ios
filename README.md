# 网易游戏 iOS 登录助手 (netease-ios)

在 Android 设备上，通过网易官服游戏自带的 **MPay / GMBridge** 组件，**一键登录**同一网易账号下的 **iOS 端角色**；也支持一键**还原为安卓角色**。

全程**免 Root、免抓包、免修改游戏安装包或签名、不内嵌任何第三方登录 SDK**，账号验证完全在目标游戏客户端原生的网易登录窗口中完成。

---

## 核心特性

- **一键登录（Single-pass）**：自动读取游戏当前登录账号并注入登录准备，无需手动两步识别。
- **通用 MPay 支持**：不局限于单一游戏，直接选择本机已安装的网易官服游戏，自动识别游戏代号（如 `ma75`）。
- **还原安卓角色**：同一通道反向注入。
- **保留官方包体与签名**：不对目标游戏 APK 做任何重打包或注入修改。
- **账号隐私**：界面不显示账号与游戏代号，仅提示「已记录」。

---

## 适用前提

1. 目标游戏需为**网易官服客户端**（B 站服、应用商店渠道服等非网易官服账号体系不适用）。
2. 目标游戏客户端需开放导出网页桥组件 `com.netease.unisdk.gmbridge5.activity.GMWebviewActivity`（部分老架构或未导出的客户端不支持，拉起时会有明确提示）。
3. 准备文件传输支持两种通道（按需选择）：
   - **标准缓存方式（默认）**：通过 `<游戏包名>.widget_file_provider` 写入缓存目录（适用于《光·遇》等开放了缓存接口的游戏，免目录授权）。
   - **共享目录方式（SAF · 阴阳师等适用）**：针对未包含 `widget_file_provider` 的游戏，通过系统目录选择器授权内部存储 `Android/media`（或对应子目录）后写入。

---

## 使用步骤（一键登录）

1. **选择目标游戏**：点击顶部目标栏，从本机已安装应用列表选择网易官服游戏。
2. **打开游戏并登录一次**（若游戏内尚未登录过任何账号，本工具会提示先登录，以便读取账号上下文）。
3. **回到助手，点「一键登录 iOS 角色」**：助手自动拉起游戏并注入登录准备。
4. **在游戏内点「切换账号」重新登录**：若切号弹窗此前已打开，先点右上角「×」重开刷新列表，再登录即可进入 **iOS 角色**。

> 注意：注入完成后**游戏不缓存账号记录**（免密 ticket 机制的固有行为），无论切 iOS 还是还原安卓，都需在游戏里**重新输入账号密码登录**（或按登录窗口提示验证一次）；每次切换均是如此。

---

## 还原为安卓角色

在操作模式中选择「**还原为安卓角色**」，再点主按钮，同样走一键通道，把账号切回安卓端。切回后与切换 iOS 一样，**游戏不缓存账号记录，需重新输入账号密码登录**。

---

## 工作原理简述

1. **本地回环瞬时通信**：每次操作仅在 `127.0.0.1` 绑定随机端口并生成一次性 24 字节随机 Nonce，配合严格 `Host` / `Origin` 校验与 CSP 策略，完成后立即销毁。
2. **自动读取账号上下文（一键）**：拉起目标游戏的 `GMWebviewActivity`，页面通过 JS 桥调用 `gameContextInfo` 自动获取当前登录账号与 `game_id`，随后立即写入登录准备（seed）。
3. **注入登录准备**：seed 内容声明 `src_client_type = 2`（iOS，还原时用 `1`）并走 `is_from_ticket_login` 免密通道，经 `loadMpaySession` 让游戏 SDK 以对应端类型加载登录会话；45 秒后自动清理。
4. **仅在游戏官方组件内完成**：不采集、不存储、不传输密码 / 验证码 / 登录 token。

---

## 安全设计

- 零凭证暴露：seed 中 `token` 字段始终为空，不碰账号密码与验证码。
- 全链路本地：所有请求仅在本机回环地址，无任何外部服务器通信。
- 一次性与自动清理：seed 生成后 45 秒自动删除；缓冲区使用后清零。
- 界面不显示账号与代号，仅本机保存最近一次的端类型（苹果/安卓）用于状态展示。
